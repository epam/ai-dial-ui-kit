This is the number the change's core Goal is about: a consumer statically
importing only `Button` from the root now pulls 69-75% less code, because
AG Grid (and, unconditionally, Monaco/@uiw/* dependency-adjacent code that
used to sit in the same opaque shared chunk) is no longer in that reachable
set at all - confirmed structurally too (assert-static-graph.mjs: 0
forbidden-package hits), not just by the byte count dropping.

The raw entry-file-only numbers above (dial-ui-kit.js 21 KB, etc.) measure
something different and much less meaningful in isolation - the entry
barrel file's own size, not what a consumer's bundler actually resolves
into its bundle - which is exactly why Decision 6 mandated the
consumer-fixture harness as the real proof, rather than local dist/ file
sizes.
